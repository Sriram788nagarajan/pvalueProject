Tips for Setting Design Parameters

  • Choose Independent vs Paired carefully: Use independent designs for most A/B tests. Paired designs are only appropriate when the same user is measured before and after a change.
  • Be realistic about planned traffic: Enter the number of users you are confident will actually be exposed during the test, not optimistic projections.
  • Baseline matters for conversion metrics: If you know your historical conversion rate, include it. Even a rough estimate is better than assuming nothing.
  • Only enter standard deviation for continuous metrics: Skip this for binary metrics like conversion rate. Use recent production data if available.
  • Default confidence and power are usually sufficient: 95% confidence and 80% power are industry standards. Increase them only if the decision is very high risk.
  • Two-sided tests are safer by default: Use one-sided tests only if negative effects are truly impossible or irrelevant to the business.
